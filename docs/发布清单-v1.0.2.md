## 1. 这版修好了什么（给用户看的 changelog）

### ✨ 划词变成 Word 手感（本版重点）

- **工具条并入顶部栏**：不再浮在正文上方遮字；选完字，顶部栏原地变成「颜色 + 高亮 / 下划线 / 波浪线 / 删除线 / 复制 / 搜索 / 关闭」。
- **Word 式点击**：单击页面空白 = 清空选区；拖动超过 5px 才真正开始选。
- **高亮"黏在字上"**：缩放过程中高亮跟着字一起缩放，不再等重绘完才归位；切换布局 / 翻页 / 滚动也天然跟随。
  > 底层做法：高亮从"固定在屏幕上的浮层"改成**页面内部的相对坐标层**（和批注同一套机制），
  > 顺带根治了"缩放后高亮飘在页面上方"和"高亮破格溢出页面"两个老问题。
- **删除双击页面切适宽/适页、双击/三击选词等从未实现的移植代码**。

### 🌙 夜晚模式现在是真的夜晚

- PDF **画布反色**：黑底白字（彩色图表用 hue-rotate 抵消色相翻转；照片会变负片，属反色模式通行取舍）。
- 阅读器 UI 一起变深：侧栏（批注/目录/缩略图/信息）、搜索面板、批注卡、菜单。
- 护眼模式补全：纸变米色 + 侧栏暖色，不再只是边框变色。

### 🔍 文内搜索"搜到了却找不到"已修

- **页内高亮**：中文期刊 PDF 的文本层是**逐字 span**（一页 2900+ 个文本节点），原实现只在单个节点内查关键词 → 页面一条高亮都画不出。现在整页拼接后跨节点匹配 + 跨节点 Range 取矩形。
- **全角/空白归一化**：全角「ＣＥＯ」、被空格拆开的 "C E O"、零宽字符，都能用 `CEO` 搜到。
- **按"处"跳转**：计数不再是按页；「下一处/上一处」逐处定位并**自动滚进视野**；侧栏每页显示 `×N`。
- **高亮不刷屏**：页面只画**当前命中**（橙色 + 描边），其余命中只在侧栏列表（对齐"书签"的思路）。

### 🧩 分栏页"往下选着选着就选不了了"已修

- 真机复现：高倍缩放下栏目被切成几十个碎块（连"在 ｜AI｜ 时代"都被切开），拖选锚点落进 1~3 个字的小块 → 选区卡死。
- 修法：栏缝合并、断口必须落在栏缝上、所有行统一重算 `gutters`、栏缝范围穿过"单边行"只被通栏行截断。
- 覆盖第 1 页"通栏 + 双栏"混排、以及 200%/300% 各档缩放。

### 📝 其它

- `docs/CHANGELOG.md` 补齐本轮全部条目（含根因与验收数据）；
- `__litshelfBlocks()` 诊断钩子补充「每页栏缝（位置 + y 范围）/ 行数 / 每块首 12 字」。

## 3. 发版步骤

### ① 打包
```bash
node tools/make-portable.mjs      # → D:\dsh\文献架整合
node tools/smoke-portable.mjs
```

### ② 压 zip
```bash
powershell -NoProfile -Command "Compress-Archive -Path 'D:\dsh\文献架整合\*' -DestinationPath 'D:\dsh\LitShelf-portable-v1.0.2-win.zip' -CompressionLevel Optimal"
```
> zip 与整合版目录都在**仓库之外**（`文献架整合/` 在项目上一级），不会进 git。
> GitHub 单文件上限 100 MB，大文件一律走 **Release 资产**。

### ③ 推代码
```bash
git push origin main
```

### ④ 建 Release 并上传资产
- **Tag**：`v1.0.2`
- **Title**：`v1.0.2 — 划词手感 + 夜晚模式 + 文内搜索 + 分栏选区`
- **正文**：复制上面第 1 节
- **附件**：`LitShelf-portable-v1.0.2-win.zip`

发布后在 Release 正文最前面放一段：
> 解压后双击 `文献架 LitShelf.exe` 即用，无需安装 Node.js。
> 数据存在 `%APPDATA%\文献架 LitShelf`，整包可以随便拷贝/换电脑。
