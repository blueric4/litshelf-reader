## 2. 关键判据（怎么"像人一样"分栏的）

1. **同一水平线 且 距离不远** —— 判断"两个字是不是同一行"的两条判据，缺一不可；
2. **多行共有的竖直缝** —— 同一个 x 位置的空隙在多少行里反复出现；
   表格列缝、正文栏缝都会这样显现，巧合的缩进只出现一两次，直接被挡掉；
3. **带纵向范围的栏缝** —— 表格列缝只在表格那一段高度生效，正文栏缝只在正文段生效
   （这是"114 块 → 47 块"的关键）；
4. **形状筛选** —— 真栏缝两侧各有一整栏文字（各占页宽 28%~52% 且彼此相称），
   表格列缝往往一侧只有标签列。

## 4. 怎么运行 / 怎么打包

```bash
pnpm build          # 只构建
pnpm dist           # 构建 + 打 Windows 安装包（NSIS）→ release/
```

启动的是 `dist/main/index.mjs`（Electron 主进程）。
安装包输出在 `release/`：`文献架 LitShelf Setup <version>.exe`，支持自选安装目录、自动建桌面快捷方式。

⚠️ **当前没有应用图标**（`build/` 与 `resources/` 里没有 `.ico`），安装包会用 Electron 默认图标。
要换图标就把 `icon.ico` 放进 `build/` 目录，再跑一次 `pnpm dist`。

## 7. 本轮踩过的坑（给后来的人）

1. **诊断钩子是全局单值** —— 读 `__litshelfLines` / `__litshelfGutterInfo` 前必须校验页号，
   否则读到的是**别的页**的数据（我为此误判过至少 3 次）；
2. **`Input.dispatchMouseEvent(mouseWheel)` 在某些机器上不回包** —— 会让脚本挂到超时，
   改用 `scrollIntoView`；
3. **不要用 Escape 清选区** —— `ReaderView` 在无浮层时 Escape = 关闭阅读器回列表页，
   之后的"拖拽"全按在列表页上（这造成过一次"产品有回归"的误判）；
4. **引擎是惰性算块的** —— 不先拖一次，行/块钩子是 `null`；
5. **固定时间点采样会漏掉重绘窗口** —— 验证"缩放后立刻按下"要用密集扫描（每 20ms 一次）。
